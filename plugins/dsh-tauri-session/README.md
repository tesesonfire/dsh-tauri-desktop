# dsh-tauri-session（会话管理插件）

将 dsh 会话的「删除工作区」升级为「归档」语义，归档聊天支持完整管理：

- **搜索**：按标题（大小写不敏感）
- **排序**：归档时间 / 标题 / 消息数，升降序
- **分组**：不分组 / 按项目 / 按归档日期
- **项目筛选**：从归档数据自动聚合项目候选
- **取消归档**：会话回到 dsh 正常列表（仅移除归档记录）
- **永久删除**：丢弃归档元数据（真正的删除入口）

## manifest

- id：`com.dsh-tauri.session`
- 权限：`ui`、`storage`
- contributes：侧边栏 `archived`、面板 `archive-list`

## 测试

`test/archive.test.ts` 覆盖归档生命周期、搜索/筛选/排序、三种分组与项目聚合。
